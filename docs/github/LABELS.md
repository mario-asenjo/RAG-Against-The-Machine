# Suggested labels

Keep labels minimal and consistent with the existing repository if it already has conventions.

| Label | Purpose |
|---|---|
| `implementation` | Normal vertical implementation slice |
| `bug` | Reproducible defect/regression |
| `retrieval` | Chunking/ranking/index behavior |
| `performance` | Benchmark/timing/recall experiment |
| `generation` | Qwen/prompt/context/answer work |
| `documentation` | README/defense/docs-only |
| `evaluation` | Corrector/evaluator compatibility |
| `blocked` | Cannot proceed pending external decision/dependency |
| `bonus` | Bonus-only, never used before mandatory full pass |
